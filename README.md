# 🧳 First ever project using C++

This is a simple C++ project that allows you to **read**, **search**, and **export** travel data from a CSV file. The dataset contains information like **City**, **State**, and **Price** — ideal for managing or browsing travel options.

## 📌 Features

- 📂 **Load data** from a CSV file
- 🔍 **Search data** by city or state
- 💾 **Export selected data** to a new CSV file
